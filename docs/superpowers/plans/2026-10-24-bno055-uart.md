# BNO055 ドライバ（UART / I2C）と gamma の IMU タスク 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** BNO055 を gamma では UART（115200、PS1 = High）で 100 Hz に読み、`ImuStore` に姿勢・角速度・有効フラグ・計測時刻・計測時の首 Yaw 角を書く。起動時に待たない。通信が途絶・エラー続きなら `valid = false` に落として再初期化を繰り返す。状態機械はバスに依らず、I2C 用の薄い層（抽象バス）も rabcl に用意する。

**Architecture:** rabcl `component/bno055` に `BNO055Uart`（UART フレーム）、`BNO055Sequencer`（起動シーケンス・周期読み・再初期化。「次の操作」を出し「結果」を受ける）、`BNO055UartDriver`（Uart + Sequencer）、`BNO055RegisterBus`（抽象）+ `BNO055I2cDriver`（Bus + Sequencer）を置き、すべて偽の応答でユニットテストする。gamma ファームの `ImuTask`（FreeRTOS タスク）が `rabcl_esp32::SerialPort` で `BNO055UartDriver` をつなぎ、応答の長さだけブロック読みして 10 ms 境界で回す。軸の入れ替えは BNO055 のレジスタ、符号の約束だけファームで直す。rabbits_description に `imu_link`。

**Tech Stack:** C++17、rabcl（gtest、Docker `rabbits/ros2-jazzy-dev` で colcon）、ESP-IDF 5.5.5 / pioarduino（PowerShell で `pio run`。FreeRTOS tick 100 Hz のまま）、xacro。

**Spec:** `docs/superpowers/specs/2026-10-24-bno055-uart-design.md`（rabcl。3 章の BNO055 の事実、4 章の API、5 章のファーム、8 章の判断）。

## Review Focus

- タイムアウト後に遅れて届いた UART 応答が、再発行した要求の応答として誤って受け取られない（待ち中でなければ捨てる。形と長さを検証）。→ Task 3 `LateResponseAfterTimeoutIsIgnored`。
- BUS_OVER_RUN（`EE 07`）が数回続いても再初期化にならず、しきい値（10）で初めてソフトリセットする。→ Task 2 `BusOverrunRetriesWithoutReinit`。
- CHIP_ID が永遠に違う（配線ミス / 別チップ）とき、固まらず再初期化を繰り返し、`running()` は false のまま。→ Task 2 `WrongChipIdNeverRuns`。
- heading が 2π → 0 をまたぐとき、`WrapPi(-heading)` の yaw が [−π, π) で連続。→ Task 2 `HeadingWrapsToSignedYaw`。
- 起動中や要求を出していないときに届いたゴミを `Feed` しても状態が壊れない。→ Task 3 `GarbageWhileIdleIsIgnored`。

**Interfaces:**

- Produces（スペック 4.3 のとおり）: `BNO055UartDriver`（`Tick(now_ms, out, cap) → size_t`、`Feed(data, len, now_ms, sample) → bool`、`expected_response_len()`、`last_request_ms()`、`sequencer()`、`Restart`）、`BNO055RegisterBus`（純粋仮想 `Read(reg, data, len)` / `Write(reg, data, len)`）、`BNO055I2cDriver`（`Tick(now_ms, sample) → bool`、`sequencer()`、`Restart`）。

- `BNO055I2cDriver::Tick`: `Next` が op を返したら bus を同期で呼び、`Complete`。bus が false なら `ok = false, error = 1`。
