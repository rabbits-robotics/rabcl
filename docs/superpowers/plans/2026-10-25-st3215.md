# ST3215 ドライバと単体検証 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ST3215 のプロトコル / ドライバ（rabcl）、半二重 UART（rabcl_esp32）、gamma ファームの試験モードを作り、実機で設計メモ 5.1 の 4 項目を測る。

**Architecture:** rabcl `St3215Protocol`（純粋関数）+ `St3215`（`St3215Port` 抽象越しの 1 サーボ）。rabcl_esp32 `HalfDuplexSerial`（rabcl 非依存、送信 → エコー読み捨て → 応答）。gamma_turret_fw に `St3215Port` の薄いアダプタと `[env:st3215_test]` の対話コンソール。

**Tech Stack:** C++17、gtest（rabcl は Docker の colcon、rabcl_esp32 はホスト cmake）、ESP-IDF 5.5（pioarduino、`pio run -e st3215_test`）。

**Spec:** `rabbits_ws/src/rabcl/docs/superpowers/specs/2026-10-25-st3215-design.md`

## Global Constraints

- C++ のみ。定数は UPPER_SNAKE_CASE。include は外部 `<>` / 自リポ `""`。rabcl 系はテスト必須。rabcl に機体の値を書かない。rabcl_esp32 は rabcl に依存しない。
- コミットはユーザーの承認後、1 行の日本語。順番: rabcl → rabcl_esp32 → gamma_turret_fw。ファームの試験モードはビルドで確認し、実機 4 項目を測ってから（結果を文書に残して）コミット可否を聞く。
- プロトコル定数（設計書 3 章）: ヘッダ FF FF、LEN = パラメータ数 + 2、CHK = ~(ID + LEN + INST + …)、リトルエンディアン、負値は bit15 符号付き絶対値（負荷だけ bit10）、レジスタ番地は設計書 4.1 の表。
- 配線: UART1、TX G8、RX G10、1 Mbps、ID 1。

## Review Focus

1. 応答の前にごみ（エコーの残り、バスのノイズ）が入ったときに `ParseResponse` が FF FF を探して同期し、チェックサム不一致を黙って通さないこと → Task 1 `ParseResponseSkipsLeadingGarbage` / `ParseResponseRejectsBadChecksum`。
2. `Transfer` で応答が timeout 内に揃わなかったとき、次の `Transfer` に古いバイトが残らないこと（毎回受信を捨てる）→ Task 2 `TransferFlushesStaleInput`。
3. `St3215::Move` の負のステップが bit15 で送られ、0x8000（−0 相当）や −32768 を作らないこと → Task 1 `MoveNegativeStepUsesSignBit`。
4. 試験モードの `s` でサーボが応答を返さない（電源なし）とき、2 s でタイムアウトして次のコマンドを受け付けること → Task 3 のビルド後に実機（電源を切って `s`）で確認。
5. 試験モードを入れても通常ビルド（`stamp_p4`）のバイナリに影響しないこと → Task 3 で両環境をビルドし、`stamp_p4` の `.pio/build/stamp_p4/firmware.bin` のサイズが変わらない。

```cpp
// test/test_st3215.cpp（抜粋。全部で 16 本）
#include <gtest/gtest.h>
#include <cstring>
#include <vector>
#include "rabcl/component/st3215.hpp"
namespace rabcl {
using P = St3215Protocol;

// 送信を記録し、用意した応答（エコーは含めない）を返す
class FakePort : public St3215Port {
public:
  std::vector<std::vector<uint8_t>> sent; std::vector<uint8_t> reply; int result = 0;
  int Transfer(const uint8_t * tx, size_t tx_len, uint8_t * rx, size_t rx_len, uint32_t) override {
    sent.emplace_back(tx, tx + tx_len);
    const size_t n = std::min(rx_len, reply.size()); std::memcpy(rx, reply.data(), n);
    return result != 0 ? result : static_cast<int>(n);
  }
};

TEST(St3215Protocol, BuildPing) { uint8_t b[8]; ASSERT_EQ(6u, P::BuildPing(1, b)); const uint8_t e[] = {0xFF,0xFF,0x01,0x02,0x01,0xFB}; EXPECT_EQ(0, std::memcmp(b, e, 6)); }
TEST(St3215Protocol, BuildRead) { uint8_t b[8]; ASSERT_EQ(8u, P::BuildRead(1, 56, 2, b)); const uint8_t e[] = {0xFF,0xFF,0x01,0x04,0x02,0x38,0x02,0xBE}; EXPECT_EQ(0, std::memcmp(b, e, 8)); }
TEST(St3215Protocol, BuildWrite) { uint8_t b[16]; const uint8_t d[] = {0xAB, 0x00}; ASSERT_EQ(9u, P::BuildWrite(1, 42, d, 2, b)); const uint8_t e[] = {0xFF,0xFF,0x01,0x05,0x03,0x2A,0xAB,0x00,0x21}; EXPECT_EQ(0, std::memcmp(b, e, 9)); }
TEST(St3215Protocol, SignedEncoding) { EXPECT_EQ(0x8064, P::EncodeSigned(-100)); EXPECT_EQ(171, P::EncodeSigned(171)); EXPECT_EQ(-100, P::DecodeSigned(0x8064)); EXPECT_EQ(1234, P::DecodeSigned(1234)); EXPECT_EQ(-100, P::DecodeLoad(0x0464)); EXPECT_EQ(100, P::DecodeLoad(0x0064)); }
TEST(St3215Protocol, LittleEndian) { uint8_t b[2]; P::PutU16(0x03E8, b); EXPECT_EQ(0xE8, b[0]); EXPECT_EQ(0x03, b[1]); EXPECT_EQ(0x03E8, P::GetU16(b)); }
TEST(St3215Protocol, ResponseLength) { EXPECT_EQ(6u, P::ResponseLength(0)); EXPECT_EQ(8u, P::ResponseLength(2)); }
TEST(St3215Protocol, ParseAck) { const uint8_t r[] = {0xFF,0xFF,0x01,0x02,0x00,0xFC}; P::Response o; size_t c; ASSERT_TRUE(P::ParseResponse(r, 6, o, c)); EXPECT_EQ(1, o.id); EXPECT_EQ(0, o.error); EXPECT_EQ(0, o.len); EXPECT_EQ(6u, c); }
TEST(St3215Protocol, ParseReadData) { const uint8_t r[] = {0xFF,0xFF,0x01,0x04,0x00,0xD2,0x04,0x24}; P::Response o; size_t c; ASSERT_TRUE(P::ParseResponse(r, 8, o, c)); EXPECT_EQ(2, o.len); EXPECT_EQ(1234, P::GetU16(o.data)); }
TEST(St3215Protocol, ParseResponseSkipsLeadingGarbage) { const uint8_t r[] = {0x12,0x34,0xFF,0xFF,0xFF,0x01,0x02,0x00,0xFC}; P::Response o; size_t c; ASSERT_TRUE(P::ParseResponse(r, 9, o, c)); EXPECT_EQ(9u, c); }
TEST(St3215Protocol, ParseResponseRejectsBadChecksum) { const uint8_t r[] = {0xFF,0xFF,0x01,0x02,0x00,0xFD}; P::Response o; size_t c; EXPECT_FALSE(P::ParseResponse(r, 6, o, c)); }
TEST(St3215Protocol, ParseResponseRejectsShort) { const uint8_t r[] = {0xFF,0xFF,0x01,0x04,0x00,0xD2}; P::Response o; size_t c; EXPECT_FALSE(P::ParseResponse(r, 6, o, c)); }

TEST(St3215, MoveWritesAccPositionTimeSpeed) { FakePort port; port.reply = {0xFF,0xFF,0x01,0x02,0x00,0xFC}; St3215 s(port, 1); ASSERT_TRUE(s.Move(171, 1000, 50)); const uint8_t e[] = {0xFF,0xFF,0x01,0x0A,0x03,0x29,0x32,0xAB,0x00,0x00,0x00,0xE8,0x03,0x00}; ASSERT_EQ(1u, port.sent.size()); EXPECT_EQ(std::vector<uint8_t>(e, e + 14), port.sent[0]); }
TEST(St3215, MoveNegativeStepUsesSignBit) { FakePort port; port.reply = {0xFF,0xFF,0x01,0x02,0x00,0xFC}; St3215 s(port, 1); ASSERT_TRUE(s.Move(-171, 1000, 50)); EXPECT_EQ(0xAB, port.sent[0][7]); EXPECT_EQ(0x80, port.sent[0][8]); }
TEST(St3215, ReadStatusDecodesFields) { FakePort port; St3215 s(port, 1);
  // 56..70 の 15 バイト: pos 1234, speed -50 (0x8032), load -100 (0x0464), volt 74, temp 31, [64,65]=0, moving 1, [67,68]=0, current -7 (0x8007)
  uint8_t d[15] = {0xD2,0x04, 0x32,0x80, 0x64,0x04, 74, 31, 0,0, 1, 0,0, 0x07,0x80};
  uint8_t r[6 + 15] = {0xFF,0xFF,0x01,0x11,0x00}; std::memcpy(r + 5, d, 15); uint8_t sum = 0x01 + 0x11 + 0x00; for (uint8_t v : d) sum += v; r[20] = ~sum; port.reply.assign(r, r + 21);
  St3215Status st; ASSERT_TRUE(s.ReadStatus(st)); EXPECT_EQ(1234, st.position); EXPECT_EQ(-50, st.speed); EXPECT_EQ(-100, st.load); EXPECT_EQ(74, st.voltage); EXPECT_EQ(31, st.temperature); EXPECT_TRUE(st.moving); EXPECT_EQ(-7, st.current);
  EXPECT_EQ(0x38, port.sent[0][5]); EXPECT_EQ(15, port.sent[0][6]); }
TEST(St3215, SetModeUnlocksWritesLocks) { FakePort port; port.reply = {0xFF,0xFF,0x01,0x02,0x00,0xFC}; St3215 s(port, 1); ASSERT_TRUE(s.SetMode(P::Mode::STEP)); ASSERT_EQ(3u, port.sent.size()); EXPECT_EQ(55, port.sent[0][5]); EXPECT_EQ(0, port.sent[0][6]); EXPECT_EQ(33, port.sent[1][5]); EXPECT_EQ(3, port.sent[1][6]); EXPECT_EQ(55, port.sent[2][5]); EXPECT_EQ(1, port.sent[2][6]); }
TEST(St3215, NoResponseCountsTimeout) { FakePort port; port.result = 0; St3215 s(port, 1); EXPECT_FALSE(s.Ping()); EXPECT_EQ(1u, s.timeouts()); }
TEST(St3215, ErrorByteIsKept) { FakePort port; port.reply = {0xFF,0xFF,0x01,0x02,0x20,0xDC}; St3215 s(port, 1); EXPECT_TRUE(s.Ping()); EXPECT_EQ(0x20, s.last_error()); }
}  // namespace rabcl
```
